Apache Commons Libraries – Description and Functions
Apache Commons is a collection of reusable Java libraries that simplifies common programming tasks. Each library provides specific functionality and can be added independently to your Java project.
============================================
A. Core utility libraries
============================================
1.Commons Lang	
Extends standard Java classes	
StringUtils, DateUtils, NumberUtils, ObjectUtils
============================================
// StringUtils
StringUtils.isBlank(" ");             // true
StringUtils.defaultString(null);      // ""
StringUtils.isNumeric("123");         // true
StringUtils.capitalize("hello");      // Hello
StringUtils.reverse("hello");         // olleh
// ObjectUtils
ObjectUtils.defaultIfNull(null, "N/A"); // N/A
ObjectUtils.isEmpty("");               // true
// NumberUtils
NumberUtils.toInt("123");              // 123
NumberUtils.isCreatable("12.5");       // true
NumberUtils.max(10, 20, 30);           // 30
============================================
2.Commons IO
Simplifies file and stream operations
FileUtils, IOUtils, FilenameUtils
============================================
// FileUtils
FileUtils.copyFile(source, target);

FileUtils.writeStringToFile(file, "Hello", StandardCharsets.UTF_8);
// IOUtils
String data = IOUtils.toString(inputStream, StandardCharsets.UTF_8);
IOUtils.copy(inputStream, outputStream);

FilenameUtils.getExtension("invoice.pdf"); // pdf
FilenameUtils.getName("/files/invoice.pdf"); // invoice.pdf

GenericObjectPool<StringBuilder> pool =
    new GenericObjectPool<>(new BasePooledObjectFactory<StringBuilder>() {
        public StringBuilder create() {
            return new StringBuilder();
        }

        public PooledObject<StringBuilder> wrap(StringBuilder obj) {
            return new DefaultPooledObject<>(obj);
        }
    });

pool.returnObject(obj);
